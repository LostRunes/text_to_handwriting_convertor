### Problem 1: Solve the quadratic equation

Solve for \( x \): \( 2x^2 - 7x + 3 = 0 \)

**Step 1:** Use the quadratic formula:

\[
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
\]

Here \( a = 2 \), \( b = -7 \), \( c = 3 \). So the discriminant is

\[
\Delta = b^2 - 4ac = (-7)^2 - 4(2)(3) = 49 - 24 = 25
\]

**Step 2:** Substitute:

\[
x = \frac{7 \pm \sqrt{25}}{4} = \frac{7 \pm 5}{4}
\]

- If we take \(+\): \( x = \frac{12}{4} = 3 \)
- If we take \(-\): \( x = \frac{2}{4} = \frac{1}{2} \)

\[
\boxed{x = 3 \quad \text{or} \quad x = \tfrac{1}{2}}
\]

### Problem 2: Evaluate the integral

\[
\int_0^{\pi} \sin^2 x \, dx
\]

Using \( \sin^2 x = \frac{1 - \cos 2x}{2} \):

\[
\begin{aligned}
\int_0^{\pi} \sin^2 x \, dx &= \frac{1}{2}\int_0^{\pi} (1 - \cos 2x)\, dx \\
&= \frac{1}{2}\left[ x - \frac{\sin 2x}{2} \right]_0^{\pi} \\
&= \frac{\pi}{2}
\end{aligned}
\]
